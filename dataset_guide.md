# Dataset Creation Guide for AI Image Detection

This guide will help you build a comprehensive dataset for training your AI vs Real image classifier.

## Overview

You need two main categories:
1. **Real Images**: Photos taken with actual cameras/phones
2. **AI Images**: Generated by diffusion models (Stable Diffusion, DALL-E, etc.)

## Dataset Structure

```
data/
├── train/
│   ├── real/          # Real camera images for training
│   └── ai/            # AI-generated images for training
├── val/
│   ├── real/          # Real images for validation
│   └── ai/            # AI images for validation
└── test/
    ├── real/          # Real images for testing (unseen)
    └── ai/            # AI images for testing (unseen generators)
```

**Recommended sizes:**
- Training: 2000-5000 images per class (real + AI)
- Validation: 400-1000 images per class
- Test: 400-1000 images per class

## Step 1: Collecting Real Images

### Sources for Real Food/Grocery Images:

1. **Your Own Photos**:
   - Take photos with different devices (iPhone, Android, DSLR, point-and-shoot)
   - Vary lighting conditions (natural, indoor, flash)
   - Different backgrounds and angles
   - Mix of close-ups and wider shots

2. **Public Datasets** (if allowed):
   - Food-101 dataset (food images)
   - Grocery Store Dataset
   - Unsplash (check licensing)
   - Your own company's product photos

3. **Key Considerations**:
   - **Diverse cameras**: Different brands/models produce different PRNU patterns
   - **JPEG quality**: Mix of high (90-95) and medium (70-85) quality
   - **File formats**: Primarily JPEG (for Q-table analysis), some PNG
   - **No AI enhancement**: Avoid images processed with AI upscaling/noise reduction
   - **Variety**: Different food types, packaging, backgrounds

## Step 2: Generating AI Images

### Option A: Stable Diffusion (Recommended - Free)

1. **Install Stable Diffusion**:
   ```bash
   pip install diffusers transformers accelerate
   ```

2. **Generate Images**:
   ```python
   from diffusers import StableDiffusionPipeline
   import torch
   
   pipe = StableDiffusionPipeline.from_pretrained(
       "runwayml/stable-diffusion-v1-5",
       torch_dtype=torch.float16
   )
   pipe = pipe.to("cuda")
   
   prompts = [
       "a photo of fresh apples on a wooden table",
       "grocery store shelf with packaged food products",
       "close-up of a burger with fries",
       # ... more prompts
   ]
   
   for prompt in prompts:
       image = pipe(prompt).images[0]
       image.save(f"data/train/ai/{prompt[:20]}.jpg")
   ```

3. **Use Different Models**:
   - Stable Diffusion v1.5
   - Stable Diffusion v2.1
   - Stable Diffusion XL
   - This ensures your model generalizes across generators

### Option B: DALL-E / Midjourney

- Export generated images
- Ensure they're saved as JPEG (not PNG) for consistency
- Label them clearly as AI-generated

### Option C: Use Pre-generated Datasets

- **DeepFake Detection Datasets**: Some include AI-generated images
- **GAN-generated datasets**: Though less relevant for diffusion models

### Key Considerations for AI Images:

- **Save as JPEG**: Convert PNG outputs to JPEG (quality 85-95) to match real images
- **No post-processing**: Don't apply filters that might add camera-like artifacts
- **Diverse prompts**: Food, groceries, packaging, different styles
- **Multiple generators**: Train on SD v1.5, test on v2.1 or DALL-E

## Step 3: Data Preprocessing

### What the Training Script Does Automatically:

1. **Resizing**: All images to 224x224 or 384x384 (for EfficientNet)
2. **Normalization**: ImageNet statistics
3. **Augmentation** (training only):
   - Random rotation (±15°)
   - Color jitter
   - Random horizontal flip
   - JPEG compression simulation (quality 60-95)

### Manual Preprocessing (Optional):

If you want to preprocess before training:

```python
from PIL import Image
import os

def preprocess_image(input_path, output_path, size=(384, 384)):
    img = Image.open(input_path)
    img = img.convert('RGB')
    img = img.resize(size, Image.LANCZOS)
    img.save(output_path, 'JPEG', quality=85)
```

## Step 4: Quality Checks

### Before Training, Verify:

1. **Balance**: Roughly equal real/AI images
2. **Format**: Mostly JPEG (PNG is okay but Q-table features won't work)
3. **Size**: Images should be at least 224x224
4. **Corruption**: Remove corrupted/invalid images

## Common Issues & Solutions

### Issue: "Not enough real images"
**Solution**: 
- Use data augmentation (handled automatically)
- Collect more photos from different sources
- Consider using public datasets (with proper licensing)

### Issue: "AI images look too different from real"
**Solution**:
- Save AI images as JPEG (not PNG)
- Apply mild compression to match real images
- Use diverse prompts that match real photo styles

### Issue: "Model overfits"
**Solution**:
- Increase dataset size
- Use more aggressive augmentation
- Add regularization (dropout, weight decay)
- Ensure train/val/test splits are truly separate

## Recommended Dataset Sizes

- **Minimum viable**: 500 real + 500 AI (total 1000)
- **Good**: 2000 real + 2000 AI (total 4000)
- **Excellent**: 5000+ per class (total 10000+)

More data = better generalization, especially across different generators and cameras.
